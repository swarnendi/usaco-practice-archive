## 🛠️ Getting Started

### Prerequisites
You will need a C++ compiler supporting C++11 or later (such as `g++` or `clang++`).

### Compiling and Running Locally
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd usaco-practice
   ```

2. **Compile a solution:**
   ```bash
   g++ -O2 -Wall -std=c++17 blist.cpp -o blist
   ```

3. **Run the executable:**
   * **For standard I/O (newer USACO problems):**
     ```bash
     ./blist
     ```
   * **For file I/O (older USACO problems):** Ensure the required `.in` file (e.g., `blist.in`) is in the same directory before running `./blist`, which will generate the corresponding `.out` file.
